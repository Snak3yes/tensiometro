# tensiometro
sistema para controle de máquina via CLP, objetivo da máquina é realizar a medição da tensão superficial de um stencil levando o sensor até algumas posições predefinidas e coletando suas medições, e realizar a inspeção visual dos furos do stencil comparando as capturas das imagens com o gerber do stencil para validar a limpeza correta sem obstruções
