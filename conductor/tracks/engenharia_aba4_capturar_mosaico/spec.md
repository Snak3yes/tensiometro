# Especificação: Engineering Wizard Aba 4 - Capturar Mosaico

Track ID: engenharia_aba4_capturar_mosaico
Tipo: Feature
Estimativa: 2-3 dias

## Descrição
Implementar widget para capturar mosaico do stencil através de grid automático.

## Requisitos Funcionais

### RF1. Grid Automático
- Calcular rows/cols baseado em área
- Configurar overlap
- Estimar FOVs

### RF2. Definição de Cantos
- Definir canto 1 (X1, Y1)
- Definir canto 2 (X2, Y2)
- Calcular área

### RF3. Captura
- Executar grid
- Capturar imagens
- Stitch mosaico

### RF4. Preview
- Exibir mosaico
- Zoom/pan
- get_mosaic_data()
