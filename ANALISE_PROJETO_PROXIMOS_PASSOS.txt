 1. OBJETIVO DO PROJETO
================================================================================

O projeto visa criar um sistema completo para:

  a) MEDIÇÃO DE TENSÃO DO STENCIL
     - Medir a tensão superficial de stencils usados nas printers SMT
     - Usar sensor AS-120N conectado via serial
     - Movimentar a head em grid NxN para múltiplas medições
     - Registrar valores medidos em JSON para consulta posterior

  b) INSPEÇÃO VISUAL DOS FUROS DO STENCIL
     - Validar a qualidade da limpeza do stencil
     - Usar luz de fundo (backlight) para iluminar os furos
     - Capturar imagens com câmera industrial
     - Detectar obstruções nos furos (análise de "branco" vs "não-branco")
     - Gerar relatórios de aprovação/reprovação

  c) GERAÇÃO DE IMAGEM MAPA (STITCHING)
     - Capturar múltiplas imagens em grade
     - Cortar bordas para eliminar distorções de lente
     - Montar imagem panorâmica completa do stencil
     - Sobrepor máscaras do Gerber para inspeção

  d) RASTREABILIDADE DE STENCILS
     - Histórico individual por stencil físico
     - Análise de tendência de degradação
     - Alertas automáticos de manutenção
